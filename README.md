# carousel-kit

Claude Code skill: locked-design Instagram carousels. Clay figure decks and tweet cards, using your own name, photos and colours.

```bash
git clone https://github.com/Dartagnan98/carousel-kit.git ~/.claude/skills/carousel-kit
cd ~/.claude/skills/carousel-kit && npm install && npx playwright install chromium-headless-shell
```

Set yourself up in `assets/profile.js`, add your images (`GUIDE.md` walks through photos, the clay figure and folders), then run `/carousel-kit clay <topic>` or `/carousel-kit twitter <topic>`.
